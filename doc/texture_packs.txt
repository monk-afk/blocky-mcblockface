SquareOne Core Server Texture Override Reference
================================================

SquareOne Core can replace textures named by registered node and item
definitions without changing the corresponding mods. This is server-side
configuration: the server applies the resulting definitions and sends the
referenced media to connecting clients.

Media and override locations
----------------------------

The server collects media recursively from these locations, in descending
priority:

1. `textures/server/` in the server's user data directory
2. the selected game's `textures/` directory
3. each loaded mod's `textures/`, `sounds/`, `media/`, `models/`, and `locale/`
   directories

Texture override rules are read recursively from:

1. the directory configured by the `texture_path` setting
2. the selected game's `textures/` directory

For a server-wide override outside the game, put the replacement image and
`override.txt` under the user data directory's `textures/server/`, then set
`texture_path` to that same directory. The image must be in a media location as
well as referenced by an override rule; otherwise the server can advertise the
new texture name without having the file to send to clients.

Restart the server after changing startup media or override rules.

Override syntax
---------------

Each non-empty, non-comment line of `override.txt` has three
space-separated fields:

    itemname target texture

For example:

    default:dirt_with_grass sides default_stone.png
    default:sword_steel inventory my_steel_sword.png

Multiple targets can be given as a comma-separated list:

    default:tree top,bottom my_special_tree.png

Texture modifiers are accepted as part of the texture field:

    default:dirt_with_grass sides default_stone.png^[brighten

Empty lines and lines beginning with `#` are ignored.

Targets
-------

| Target     | Meaning                                           |
|------------|---------------------------------------------------|
| `left`     | x- face                                           |
| `right`    | x+ face                                           |
| `front`    | z- face                                           |
| `back`     | z+ face                                           |
| `top`      | y+ face                                           |
| `bottom`   | y- face                                           |
| `sides`    | x-, x+, z-, and z+ faces                          |
| `all`, `*` | all faces                                         |
| `special1` | first entry in `special_tiles`                    |
| `special2` | second entry in `special_tiles`                   |
| `special3` | third entry in `special_tiles`                    |
| `special4` | fourth entry in `special_tiles`                   |
| `special5` | fifth entry in `special_tiles`                    |
| `special6` | sixth entry in `special_tiles`                    |
| `inventory` | inventory texture                                |
| `wield`    | texture displayed while the item is held           |

Nodes support all targets. Other items support only `inventory` and `wield`.

The `special1` through `special6` targets correspond directly to entries in a
node definition's `special_tiles` list. Their visual meaning depends on the
node's draw type.
